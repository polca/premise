# First car-import dependency review

The actual nine-root CLIC car import initially refused 47 correspondences in its
first ecoinvent 3.12 cut-off cohort. Twenty-nine unchanged direct correspondences
now have exact-profile approvals. Repeating the same import reduces that cohort
to eighteen refusals. This is not the total for later cohorts or car-sector
qualification.

The review checks twenty-nine source references and fifty-eight native release
references. Every approved reference is positive one of the same declared unit.
Products include car components and infrastructure, HDPE/HIPS granulate,
identified chemicals and oxides, delivered water and voltage-specific grids.
Native low-alloy steel explicitly includes hot rolling. The xx-prefixed
praseodymium-oxide process is nonempty and models the named oxide. Neither a
prefix nor matching spelling alone establishes a functional match.

Complete native supply is an explicit screening proxy. Source production shares
and final market transport, losses and internal uncertainty are replaced where
present; the caller's signed purchase, uncertainty and separate inputs remain.
The approval does not claim equivalent scores. Weak native graphite data,
rare-earth allocation, historical component designs, differing factory output
and biosphere exclusions are retained in warnings. No new density, purity,
contained-metal, lifetime, occupancy or recovery multiplier is introduced.

Only mapping approval data and packaged evidence change. The Brightpath runtime
and its existing migration rules are unchanged for these twenty-nine matches;
prior Premise approval operations are unchanged. The packaged Brightpath review
contains identities and hashes, not full licensed inventories.

Five focused Brightpath tests verify both caller signs, normal uncertainty,
ownership, both native target releases and refusal of another source release.
The remaining treatment, freight, hydrogen and recipe cases require separate
review. None is authorized by this approval group.
