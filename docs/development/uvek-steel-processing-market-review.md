# Preserve rolling while updating the native steel mix

The exported native RER “Steel, low-alloyed, at plant” mixture still used its historical converter/EAF shares even though its suppliers had been regionalised. The publisher description identifies a production/consumption mix plus hot rolling. Treating it as a bare steel market would remove a real processing service.

An exact YAML declaration now identifies that existing one-kg product and its two steel suppliers. Only their basket changes to IAM technology shares. Its original total steel-input quantity is read from the inventory, not hardcoded in the mapping. Hot rolling and every other ancillary exchange retain their signed quantities and supported uncertainty. The shared market builder creates twelve regional products plus a World mix, and its usual forwarding/relinking logic redirects the original source and consumers. World purchases the regional processed products; it adds no second rolling service. There is no additional helper process or separate UVEK sector engine.

This needs an adaptation in the shared Steel module: its old market-name filter cannot select a native processing product, and the default ancillary selector would discard rolling because it also uses kg. The new code only prepares arguments for the existing `process_and_add_markets` method. It uses the builder's existing `normalize_before_conversion` option so a genuine material-input basis other than one is preserved. Guards reject a changed production reference, missing/wrong-product/wrong-unit suppliers, negative production-basket entries and non-finite quantities. All ancillary signs are retained. Steel validation now recognises the exact processing-market identity, checks its material basis and IAM secondary share, and includes its forwarding/consumer links. Rolling cannot conceal a missing steel supplier merely because it also uses kg. Existing ecoinvent selectors and market construction remain unchanged.

The retained RER processing inventory is an explicit geography/historical-technology screening proxy for other IAM regions. Historical uncertainty on the old converter/EAF shares is replaced by deterministic IAM scenario shares, as for ordinary Premise markets; uncertainty on retained processing is preserved. This does not establish equivalent source/native scores. Warnings and dataset metadata record those limitations.

Validation: 211 focused steel/transformation/validation tests pass, including the existing ecoinvent version/system-model cases, six signed/zero processing and non-unit-basis cases, and six invalid-basket/reference guards. Ruff passes for the steel/test files; validation retains its four pre-existing findings and adds none. Generated documentation references pass their drift check. Real encrypted REMIND SSP2-NPi 2050 preparation still has 75 imports and 12,022 base records; the shared update returns 12,516 activities and passes exhaustive graph validation. Its Brightway inventory contains thirteen processing markets. All twelve regional steel baskets retain the native material basis and rolling quantity/uncertainty; World carries processing only through the regional products. There are no nonzero consumers of the original RER forwarder. Positive and negative EUR processed-steel demands have finite LCIs and reverse sign consistently. The source database metadata remains unchanged during the audit.

The public steel gate stays closed pending combined-sector regression and a real target year with positive advanced steel production. The 2050 SSP2-NPi case has zero hydrogen-DRI production, so its absence from that year's markets is correct. No Brightpath resource or database schema migration is introduced in this change.

Follow-up integration: the normal combined biomass/electricity/heat/cement/steel workflow passes all shared updates and exhaustive graph checks, completes its Brightway export and standard reports, and writes 14,488 activities. The processing audit passes again on that combined export: thirteen processing markets, retained rolling quantities/uncertainty, no nonzero old-RER consumers, and two signed finite LCIs. A separate unmodified REMIND SSP2-NPi 2100 run has positive hydrogen DRI in EUR; all twelve regional processing-market hydrogen shares match their actual target-year IAM shares. World is a composite of regional products and is not tested as a direct generator basket. No 2100 export is claimed.

The next filter audit found native specialty and best/worst steel producers omitted by the old lowercase “steel production” selector for the shared “other producers” stage. Those complete distinct products must be assessed outside the ordinary IAM grade mix. Reinforcing-steel import variants and allocated battery-recycling steel also need explicit boundary dispositions. Public steel support remains gated until these cases are resolved. Combined/advanced-year evidence does not establish the other unfinished sectors or complete native steel coverage.
